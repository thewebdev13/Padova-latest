Padova WhatsApp helper (Owner + Staff PC) — Baileys link
========================================================

Login once (important)
- First run: scan QR once (WhatsApp → Linked devices).
- Later days: just start the helper — it reuses the saved login on this PC.
- Saved under your user folder (~/.padova/…), so updating/unzipping a new
  helper zip does NOT force a new QR.
- New QR only if: you ran logout, cleared Linked devices on the phone,
  or WhatsApp itself asks to re-link.

What this does
- Links WhatsApp on THIS computer.
- Reads incoming reservations: text · PDF · screenshots · voice notes
  → Padova drafts / AI booking path (QA).
- Reacts 👀 / ✅ / 📝 / ⚠️.
- Staff assistant (DEFAULT ON): say "hi" / "help" → menu.
- Same config on Owner PC and Staff PC.

One-time setup
1. Install Node.js 24 if needed (https://nodejs.org).
2. Unzip. Terminal in this folder: npm install
3. config.json is filled for QA (do not change token/url unless told).

Every day
1. Double-click Start-Padova-WhatsApp.command (Mac) or .bat (Windows)
2. First day only: scan QR. Later: wait until page says Connected.
3. Leave helper running; PC stay awake.
4. Test: send "hi" → help menu.

Two PCs
- Same zip / same config. Each PC links its own WhatsApp once.
- Do not link the same phone on two helpers at once.

Stop
- Close Terminal / Ctrl+C. Login stays saved for next start.
