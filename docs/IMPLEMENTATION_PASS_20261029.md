Continued the existing checkout and branch `codex/padova-v1`. The current US `padova` foundation, installed adapter, source evidence, test schemas and individual authentication remain authoritative. The four decisions in `OWNER_DECISIONS_20261029.md` are resolved implementation rules.

## Implemented

- Independent travel edits preserve original rows, prior itinerary versions, actor/reason and optimistic edit versions. Flight/hotel dates, providers, travelers, confirmations, local times, flight/ticket details, room and benefits can change without rebuilding a booking.
- Fulfillment metadata edits retain collapsed account/quote/restriction fields. Financial corrections append a reversal/replacement, restoring exact original lots where applicable. Actual supplier payments/allocations remain attributed to their actual payee; separate source credits/debts are visible for reconciliation. Actual refunds/rewards must be reconciled before reversing dependent funding.
- Outside points retain program/instrument, actual source, holder, whole quantity, exact quoted rate/unit, agreed cost, mechanism, booked-through, notes and the linked travel/provider/confirmation. Optional taxes/fees create a separate cash component. Full/partial actual source payments and per-source paid/due/status are separate from cost. No outside-source inventory/rebate is invented.
- Amex Pay With Points records gross redemption and a pending expected rebate separately. Actual issuer receipt restores proportional original basis; an actual spent-reward reversal may expose a negative owned position with unresolved attention. Chase Points Boost preserves the actual redemption quote and comparison prices without adding comparison-price income.
- Existing assets remain usable without fabricated catalog identities. Descriptive asset edits retain ownership, original acquisition, quantity, basis, source and movement history; current expiry governs use. Customer-owned value requires a named linked owner and zero Padova acquisition/use economics, and cannot be sold as Padova inventory.
- Default canceled referrals reduce unearned obligations to zero; explicit relationship terms can retain an agreed amount. Commission-receipt/travel payout gates remain enforced. Paid history stays intact, with append-only recovery receivable adjustments when revised earnings fall below prior payments.
- Employee entry uses compact traveler search and operational fields. An actual receipt entered before billing remains customer credit rather than creating a fictitious charge/allocation. Owner-only historical records and independent financial permissions are enforced on the server.
